# 42 iPad Synchronized Video Player (PWA + WebSocket Server)

Профессиональная система синхронного воспроизведения 42 видеороликов на 42 планшетах iPad для выставок, инсталляций, музеев и медиафасадов.

---

## 🌟 Ключевые возможности

1. **Локальное хранение видео на каждом iPad (IndexedDB)**:
   - Видеофайлы выбираются прямо на iPad через системный диалог iOS («Файлы» или «Фото») и сохраняются в базу данных браузера (IndexedDB).
   - После сохранения видео хранится локально на устройстве: интернет-трафик для потокового видео не расходуется, файлы мгновенно подхватываются даже после перезагрузки страницы или выключения iPad.

2. **Высокоточная субкадровая синхронизация**:
   - **NTP-синхронизация часов**: каждый iPad калибрует свое внутреннее время относительно сервера с фильтрацией сетевых всплесков Wi-Fi (точность $\pm 5-15$ мс).
   - **Упреждающий старт (Scheduled Playback)**: запуск видео происходит строго в назначенный будущий миллисекундный таймштамп сервера.
   - **Адаптивная коррекция рассинхрона (Drift Correction)**: при возникновении дрифта ($> 35$ мс) скорость воспроизведения плавно подстраивается (`playbackRate = 0.98` или `1.02`), устраняя расхождения без рывков звука и видео. При сильном отставании ($> 220$ мс) выполняется точечная перемотка (hard seek).

3. **PWA Standalone & Полноэкранный режим (Fullscreen)**:
   - Поддержка запуска в полноэкранном режиме как веб-приложение (PWA) без рамок и адресной строки Safari («На экран «Домой»).
   - Экран **«Встать на взвод (ARM)»**: обход жесткой политики автовоспроизведения iOS (Autoplay Policy), перевод в полный экран и активация **Screen Wake Lock API** (экран iPad не гаснет и не блокируется во время показа).

4. **Панель управления (Admin Dashboard)**:
   - Живой мониторинг всех 42 iPad в виде наглядной интерактивной сетки.
   - Отображение статуса каждого планшета: Онлайн / Офлайн / Имя файла / Текущий таймкод / Рассинхрон в мс / Пинг / Заряд батареи.
   - Мастер-кнопки: **СТАРТ ВСЕХ**, **ПАУЗА**, **СТОП**, **В НАЧАЛО**, зацикливание (**Loop**).
   - Таймлайн со скраббером (перемотка всех 42 планшетов одновременно).
   - Функция **«Мигнуть номерами» (Identify)**: экран выбранного или всех iPad загорается ярким цветом с гигантским номером слота — позволяет мгновенно проверить физический порядок расстановки планшетов.
   - Функция **Блэкаут (Blackout)**: мгновенное дистанционное затемнение всех экранов в паузах между показами.

## 🚀 Быстрый старт

### 1. Установка и запуск сервера
Сервер можно запустить на любом компьютере (ноутбук, Mac mini, мини-ПК), подключенном к одной Wi-Fi сети с планшетами iPad:

```bash
# Перейдите в каталог проекта
cd iPadPlayer

# Установка зависимостей
npm install

# Запуск сервера
npm start
```

При запуске в консоли отобразятся локальные IP-адреса:
```text
=================================================================
🚀 iPad Synchronized Video Player Server v1.0.0
   Configured for 42 iPad devices
=================================================================
📱 Client URL for iPads:
   👉 http://192.168.1.100:3000

🎛️  Admin Dashboard URL:
   👉 http://192.168.1.100:3000/admin.html
=================================================================
```

## 📱 Инструкция по настройке планшетов iPad

### Шаг 1: Подключение к сети
- Подключите все 42 iPad и компьютер с сервером к одной локальной Wi-Fi сети (рекомендуется Wi-Fi 5 ГГц / роутер с поддержкой большого количества клиентов, либо изолированная подсеть).

### Шаг 2: Открытие и добавление как PWA
1. Откройте Safari на iPad и перейдите по адресу: `http://<IP_СЕРВЕРА>:3000`.
2. Нажмите кнопку «Поделиться» (иконка квадрата со стрелкой вверх в Safari).
3. Выберите пункт **«На экран «Домой» (Add to Home Screen)**.
4. Запустите приложение с домашнего экрана iPad — оно откроется как автономное PWA приложение без адресных строк Safari.

### Шаг 3: Выбор слота и видеофайла на iPad
1. В правом верхнем углу нажмите кнопку шестеренки ⚙️ («Настройки»).
2. В выпадающем списке выберите номер устройства (например, **iPad #01**).
3. В блоке «Локальный видеофайл» нажмите **«Выбрать файл»** и укажите соответствующий ролик из приложения «Файлы» или «Фото».
4. Дождитесь надписи «Успешно сохранено». Видео записано в постоянную память браузера (IndexedDB).
5. Нажмите **«Сохранить настройки»**.

### Шаг 4: Постановка «На взвод» (Arming)
1. На экране появится кнопка **«⚡ ВСТАТЬ НА ВЗВОД (ARM)»**.
2. Оператор один раз нажимает эту кнопку на каждом iPad:
   - Приложение разворачивается на весь экран.
   - Разблокируется звуковой и видео-тракт iOS.
   - Активируется блокировка отключения экрана (Wake Lock).
   - Статус устройства на сервере меняется на 🟢 **ГОТОВ**.

## 🎛️ Управление через Admin Dashboard

Откройте в браузере на ноутбуке или планшете администратора:
`http://<IP_СЕРВЕРА>:3000/admin.html`

- В верхней панели отображается статус: сколько из 42 планшетов онлайн, взведено и загрузило файл.
- Нажмите кнопку **«Мигнуть номерами»** для проверки соответствия физических позиций планшетов их номерам.
- Нажмите **«▶ СТАРТ ВСЕХ»** для одновременного синхронного воспроизведения.
- Для перемотки используйте слайдер таймлайна в реальном времени.
- При необходимости перезагрузки страницы на конкретном iPad нажмите кнопку 🔄 на его карточке.
